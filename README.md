# Calculadora-py-com-conhecimento-atual

Este repositório contém uma calculadora simples em Python criada por mim com meus conhecimentos atuais.

## Como usar
1. Tenha Python 3 instalado.
2. Execute no terminal:
   ```bash
   python3 calculadora.py
   ```
3. Siga as instruções na tela: informe o primeiro número, o operador (+, -, * ou /) e o segundo número.
4. Quando perguntado "Quer [s]air?", digite `s` para encerrar o programa.

## Observações
- O programa valida entradas vazias e entradas não numéricas.
- Evita divisão por zero.
- Arquivo principal: `calculadora.py`.
